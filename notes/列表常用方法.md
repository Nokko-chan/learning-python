## 列表常用方法

```
Python 中的列表（list）是最常用的数据结构之一。它可以存储多个元素，支持修改、删除、添加、查找和排序等操作。

下面按照功能分类，整理一份常用列表方法教程。
```



### 1. 添加元素

#### append()

> `append()` 方法用于在列表末尾添加一个元素。

```python
>>> fruits = ['苹果', '香蕉', '橙子']
>>> fruits
['苹果', '香蕉', '橙子']

>>> fruits.append('葡萄')
>>> fruits
['苹果', '香蕉', '橙子', '葡萄']

>>> fruits.append(['西瓜', '菠萝'])  # 也可以列表作为元素添加进列表
>>> fruits
['苹果', '香蕉', '橙子', '葡萄', ['西瓜', '菠萝']]
```



#### extend()

> `extend()` 方法用于扩展列表。将另一个可迭代对象中的元素逐个添加至列表末尾。

```python
>>> fruits = ['苹果', '香蕉', '橙子']
>>> fruits.extend(['西瓜', '菠萝'])
>>> fruits
['苹果', '香蕉', '橙子', '西瓜', '菠萝']
```



#### insert()

> `insert()` 方法用于在指定位置插入值。

```python
>>> fruits = ['苹果', '香蕉', '橙子']
>>> fruits.insert(0, '西瓜')  # 在索引 0 的位置插入一个值
>>> fruits
['西瓜', '苹果', '香蕉', '橙子']
```





### 2. 删除元素

#### remove()

> `remove()` 方法用于删除指定的元素。

注意：

- 只能删除第一个匹配的元素。
- 如果元素不存在，则抛出 `ValueError` 异常。

```python
>>> fruits = ['苹果', '香蕉', '橙子']
>>> fruits.remove('香蕉')
>>> fruits
['苹果', '橙子']
```



#### pop()

> `pop()` 方法用于删除元素并且返回。
>
> 如果没有指定索引，默认删除列表最后一个元素。

```python
>>> fruits = ['苹果', '香蕉', '橙子']
>>> fruits.pop()
'橙子'
>>> fruits
['苹果', '香蕉']

>>> fruits.pop(0)
'苹果'
>>> fruits
['香蕉']
```



#### clear()

> `clear()` 方法用于清空整个列表。

```python
>>> fruits = ['苹果', '香蕉', '橙子']
>>> fruits
['苹果', '香蕉', '橙子']
>>> fruits.clear()
>>> fruits
>>> []
```



#### del

> `del` 是 Python 的关键字，不是列表方法。但是也可以通过 `del` 关键字删除列表元素，只需要给定一个索引位置。

```python
>>> numbers = [1, 2, 3, 4, 5]
>>> del numbers[0]
>>> numbers
[2, 3, 4, 5]

>>> del numbers[1:3]  # 使用切片删除
>>> numbers
[2, 5]

>>> del numbers       # 删除整个变量
```





### 3. 查找元素与统计元素

#### index()

> `index()` 方法用于查找元素索引。

注意：

- 如果存在多个相同元素，只返回第一个匹配元素的索引。

- 如果元素不存在，则会抛出 `ValueError` 异常。

```python
>>> colors = ['red', 'green', 'blue', 'pink']
>>> colors.index('pink')
3

>>> colors.index('pink', 2)  # 还可以指定搜索范围
3
```



#### count()

> `count()` 方法用于统计元素出现的次数。

```python
>>> number = [1, 2, 2, 3, 2, 4]
>>> number.count(2)
3
```



#### in / not in

> `in` 和 `not in`  是 Python 成员运算符，不是列表方法。
>
> `in` / `not in`  可以用于判断元素是否存在于列表中。

```
>>> fruits = ['苹果', '香蕉', '橙子']
>>> '苹果' in fruits
True
>>> '西瓜' not in fruits
True
```





### 4. 排序与反转列表

#### sort()

> `sort()` 方法用于对列表进行排序。

```python
>>> numbers = [5, 2, 4, 3, 1]
>>> numbers.sort()
>>> numbers
[1, 2, 3, 4, 5]

>>> numbers.sort(reverse=True)  # 使用 reverse 参数进行反转操作
>>> numbers
[5, 4, 3, 2 ,1]
```



`sort()` 方法还有一个 `key` 参数，可以用来指定排序规则：

```python
>>> fruits = ['banana', 'Apple', 'cherry']
>>> fruits.sort(key=len)  # 表示使用 len 函数的返回值作为排序规则(也就是按字符串长度进行排序)
>>> fruits
['Apple', 'banana', 'cherry']
```

`key` 参数除了可以使用函数，还可以使用方法：

```python
>>> fruits = ['banana', 'Apple', 'cherry']
>>> fruits.sort(key=str.lower)  # 表示使用字符串的 lower 方法进行排序(也就是按照小写字母排序)
>>> fruits
['Apple', 'banana', 'cherry']
```



#### sorted()

> `sorted()` 是一个内置函数，提供一个列表作为参数，它会返回排序后的新列表。
>
> `sorted()` 方法不会改变原来的列表。

```python
>>> numbers = [5, 2, 3, 4, 1]
>>> sorted(numbers)
[1, 2, 3, 4, 5]

>>> numbers
[5, 2, 3, 4, 1]

>>> sorted(numbers, reverse=True)  # 使用 reverse 参数进行反转操作
[5, 4, 3, 2, 1]
```

`sorted()` 函数也提供了一个 `key` 参数用于定制排序规则：

```python
>>> colors = ['red', 'green', 'blue', 'pink']
>>> sorted(colors, key=len)
['red', 'blue', 'pink', 'green']
```



#### reverse()

> `reverse()` 方法用于反转列表

```python
>>> numbers = [1, 2, 3, 4, 5]
>>> numbers.reverse()
>>> numbers
[5, 4, 3, 2, 1]
```



### 5. 列表复制

#### copy()

> `copy()` 方法用于浅拷贝列表。

注意：

- `copy()` 方法只是浅拷贝。如果列表内部中存在嵌套列表，内部对象仍然共享。

```python
>>> numbers = [1, 2, 3]
>>> new_numbers = numbers.copy()
>>> numbers.append(4)
>>> numbers
[1, 2, 3, 4]
>>> new_numbers
[1, 2, 3]
```



也可以使用切片来进行浅拷贝：

```python
>>> numbers = [1, 2, 3]
>>> new_numbers = numbers[:]
```
